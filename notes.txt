-------------------------------
=>functions are used to do task repeatedly at different location of a programming file.
=>functions have two parts 
    1.function definition

        ----------

    =>no statements after the return statement will not be executed

    5.sort()-to arrange the array in ascending or descending order

    10.some()

            value=parentArray.some((variable_name)=>condition)
    11.find()
        it returns the first element satisfying the condition
        syntax:
            value=parentArray.find((variable_name)=>condition)
    12.flat()
        =>used to change the dimension of an array 
        =>depth refers to how deep a nested array need to be flattened
        =>depth =infinity make the array to change its dimension directly to one dimension

    13.includes()
        =>to check the given item is present or not
            syntax:
                array.includes("item")
    14.splice()
        =>to add or remove items at different position in an array
            syntax:
            array.splice(startindex,deletecount,itemtoadded)
    15.indexOf()
        =>to get an index of an element
    16.lastIndexof()-to get an index of last element
